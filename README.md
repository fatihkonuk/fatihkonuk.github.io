# fatihkonuk.github.io

Fatih Konuk'un kişisel profil sayfası: **https://fatihkonuk.github.io** (Türkçe) · **https://fatihkonuk.github.io/en/** (English)

Deneyim, projeler, yetenekler, eğitim, iletişim formu ve indirilebilir CV içeren statik bir sayfa. Saf HTML, CSS ve JavaScript; build adımı ve bağımlılık yok. GitHub Pages `main` dalının kökünden yayınlanır.

## Yapı

```
index.html, en/index.html   Türkçe ve İngilizce sayfalar
404.html                    hata sayfası
assets/css, assets/js       stil ve betikler
assets/img, assets/fonts    görseller, ikon sprite'ı, yazı tipi
cv/                         CV (PDF)
tools/og.html               paylaşım görselinin kaynağı
```

## Yerelde çalıştırma

```sh
python3 -m http.server 8000
```

Ardından http://localhost:8000 adresini açın.

## Lisanslar ve atıflar

- Teknoloji ikonları: [Simple Icons](https://simpleicons.org) (CC0 1.0). Logolar ve marka adları sahiplerine aittir.
- Yazı tipi: [Archivo](https://github.com/Omnibus-Type/Archivo), SIL Open Font License 1.1 (`assets/fonts/OFL.txt`).
- İletişim formu [Web3Forms](https://web3forms.com) üzerinden çalışır.

Sayfanın içeriği ve görselleri Fatih Konuk'a aittir.
